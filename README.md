# 🚀 FixMate: Your Go-To Solution Platform [citation:2]

**Tagline:** Connecting Homeowners with Trusted Technicians Seamlessly. [citation:2][citation:9]

## 📖 Description

FixMate is a mobile platform that bridges the gap between customers and professional technicians. It enables users to book home repair services (Plumbing, Electrical, Cleaning, etc.) and allows technicians to accept or reject jobs dynamically. [citation:2][citation:9]

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🔐 Secure Login & Registration | Uses JWT (JSON Web Token) for authentication. |
| 👤 Role-Based Dashboards | Separate interfaces for **Customers** and **Technicians**. |
| 🛠️ Service Request & Tracking | Customers submit requests; technicians accept/reject them. |
| 💬 Real-time Messaging | In-app chat for communication between both parties. |
| 🏷️ Smart Dispatch | Location and rating-based technician matching (Uber/Pathao style). |

## 🛠️ Tech Stack

| Layer | Technology |

| **Database & ORM** | PostgreSQL, Prisma |
